# Travel Assistant Web App

A responsive full-stack web application designed to streamline trip planning, destination discovery, and itinerary management. Developed as an Object-Oriented Programming (OOP) coursework project at Guilin University of Electronic Technology (GUET).

## Features
- **Intuitive UI:** Clean and responsive interface for browsing destinations and building itineraries.
- **Dynamic Logic:** Client-side event handling and modular code structure.
- **OOP Architecture:** Structured using Object-Oriented Programming principles for clean separation of concerns and maintainability.
- **Back-End Integration:** Core server-side and data handling functionality.

## Tech Stack
- **Front-End:** HTML5, CSS3, JavaScript
- **Back-End:** Core server-side integration & logic
- **Methodology:** Object-Oriented Programming (OOP)
