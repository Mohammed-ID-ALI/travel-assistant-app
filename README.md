# WanderFlow — Full-Stack Smart Travel Assistant

A responsive full-stack web application designed to streamline trip planning, destination discovery, and itinerary management. Built with modular front-end logic, clean separation of concerns, and dual-backend integration capabilities.

---

## Features
- **Intuitive UI:** Clean and responsive interface for browsing destinations and building itineraries.
- **Dynamic Logic:** Client-side event handling and modular state management.
- **Full-Stack Architecture:** Supports standalone browser preview as well as integrated Python/Node.js backend execution.
- **Database & Data Handling:** Persistent itinerary management and server-side data handling.

---

## Tech Stack
- **Front-End:** HTML5, CSS3, JavaScript (ES6+)
- **Back-End Options:**
  - Python (`Flask`, `SQLite`)
  - Node.js (`Express`)
- **Architecture:** Object-Oriented Programming (OOP) & RESTful endpoints

---

## How to Open & Run

### 1. Instant Launch (No Server Setup Needed)
- Double-click `open_app.html` (in the root directory) or open `frontend/index.html` directly in your browser.
- Alternatively, double-click `run_app.bat` on Windows.

### 2. Run with Python Backend (`Flask` + `SQLite`)
```bash
pip install -r requirements.txt
python backend/app.py

```
> Then open `http://localhost:5000` in your browser.

### 3. Run with Node.js Backend (`Express`)
```bash
npm install
npm start
```
> Then open `http://localhost:5000` in your browser.
